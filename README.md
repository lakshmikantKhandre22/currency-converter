# 💱 Currency Converter – Real-Time Exchange Rate App

Currency Converter is a responsive web application built using **HTML, CSS, and JavaScript** that allows users to convert currencies instantly using live exchange rates fetched from an external API.

The application provides a simple and clean interface for selecting currencies, entering amounts, and viewing converted values in real time.






✨ Features

🌍 Real-Time Currency Conversion

Fetches live exchange rates directly from a currency API.

💹 Multiple Currency Support

Convert between various international currencies.

🔄 Swap Currencies

Quickly exchange source and destination currencies.

⚡ Instant Conversion

Displays converted amount instantly after selection.

🎨 Responsive UI

Works smoothly across desktop, tablet, and mobile devices.

🚨 Error Handling

Handles API failures and invalid inputs gracefully.



# 🛠 Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)

### API

* Exchange Rate API / Currency API


# 🚀 How It Works

1. Enter amount
2. Select source currency
3. Select target currency
4. Click **Convert**
5. Receive converted amount instantly
